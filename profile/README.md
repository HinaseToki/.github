# 히나세 토키 · ヒナセ トキ · Hinase Toki

> **말은 여리게, 노래는 쨍하게.**
> 사람 목소리 0%로 만든, 고음 특화 한일 이중 언어 합성 보컬이에요.

학생 팀이 처음부터 수식으로 합성해서 만든 오리지널 보컬 캐릭터예요. 녹음된 사람 음성은 학습, 분석, 합성 어디에도 쓰지 않았어요.

## 목소리 DNA (v1.1.0, 현재)
귀엽고 어린 하이톤이에요. 성도 12.8cm, 포먼트 +12%, 숨소리 10%(고음에서 5%), 밝기 3~5kHz +5dB, 비브라토 6.5Hz ±20cent, 말끝이 살짝 올라가요 (+40cent). C5 이상에서는 F1이 기본음을 따라가서 고음에서도 모음이 또렷해요.

## 다음 목표: "두 얼굴" 보이스 (v1.2 기획)
같은 토키 안에 여린 **소프트**와 쨍하게 뻗는 **파워**를 두고, 둘 사이를 넘어가는 순간을 토키의 시그니처로 만들어요. 성도 길이와 포먼트는 모든 모드에서 같아서 언제나 같은 토키로 들려요.

| 모드 | 느낌 | 주 음역 | 핵심 변화 |
|---|---|---|---|
| 소프트 (기본) | 여리고 귀여움 | G4~D5 | 숨 10%, 말끝이 올라갔다가 숨으로 빠짐 |
| 파워 | 맑고 강하게 뻗음 | A5~E6 | 숨 3%, 고역 +7dB, 어택 6ms, 넓은 비브라토 |
| 위스퍼 | 가깝고 은밀함 | G4~B4 | 숨 35%, 부드러운 어택 |
| 스마일 | 웃으며 노래함 | C5~G5 | F2 +4% (입꼬리 올림 효과) |

**곡 템플릿**: 인트로(위스퍼) → A파트(소프트) → 숨 들이쉬기 → 후렴(파워, A5~C6 롱톤) → 브릿지(위스퍼) → 최고음 E6 → 아웃트로(스마일)
